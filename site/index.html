InvoiceEndpoints.cs ASP.NET Core · EF Core 
// Paged, filtered, projected — one round trip, no tracking overhead.
app.MapGet("/api/invoices", async (
    AppDbContext db,
    [AsParameters] InvoiceQuery query,
    CancellationToken ct) =>
{
    var invoices = db.Invoices
        .AsNoTracking()
        .Where(i => i.TenantId == query.TenantId)
        .Where(i => query.Status == null || i.Status == query.Status)
        .OrderByDescending(i => i.IssuedOn);

    var total = await invoices.CountAsync(ct);

    var page = await invoices
        .Skip(query.Offset)
        .Take(query.Limit)
        .Select(i => new InvoiceDto(i.Id, i.Number, i.Total, i.Status))
        .ToListAsync(ct);

    return Results.Ok(new Paged<InvoiceDto>(page, total));
})
.WithName("ListInvoices")
.RequireAuthorization();

// Projection into a DTO so the query selects four columns instead of the whole entity.
// Cancellation passed all the way down, so an abandoned request stops work at the database.

Leads API

github.com/Amir-pce/leads-api

The contact form further down this page is not a mailto link. It posts to an ASP.NET Core API that validates the enquiry, stores it in SQL Server, and hands it to an admin page where I read it, mark where it has got to, and keep a private note against it. I built it because a form that only sends an email loses track of everything the moment the email is read.

Spam handling Four layers, cheapest first: a hidden honeypot field, five attempts per minute per address, a two-minute duplicate window, then field validation. A filled honeypot is answered 202 and stored nowhere — telling a bot it failed only makes it retry with the field cleared.
Senders, not addresses The duplicate check needs to recognise one sender flooding the form. It stores a SHA-256 of the IP rather than the address, which is enough to spot a flood and is not personal data sitting on disk.
Two indexes, both composite (Status, CreatedAtUtc DESC) serves the admin list, which is always newest-first and often filtered — one index covers the filtered and unfiltered read with no sort in the plan. (SenderHash, CreatedAtUtc DESC) serves the duplicate check.
Admin access A shared key compared in constant time, so a wrong guess leaks nothing about how much of it was right. An unconfigured key returns 503 — it locks the admin API rather than opening it.

Twelve end-to-end cases assert the status code of every path, the rejections as well as the successes. Four of them exist because the first version failed them: the validation attributes were inert until minimal-API validation was switched on, paging threw when the query string was absent, enum values travelled as bare integers, and the error handler was reporting every bad request as a server fault.
